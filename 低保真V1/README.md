# ChopChat 低保真 V1

用于检查 ChopChat 本轮交互重构的页面结构、导航、状态和关键流程。当前版本不承担最终视觉还原。

## 技术路线

- React + TypeScript + Vite
- React Router 管理页面与返回关系
- Context 管理原型数据、导航、主题和全局弹窗状态
- CSS Variables 作为设计令牌层，后续可替换为 Pencil/Figma 对应的 Token
- 页面、业务组件、通用组件和 mock 数据分层组织

## 本地运行

```bash
npm install
npm run dev
```

构建检查：

```bash
npm run build
```

## 当前交互边界

- 左侧导航为全局功能中心：定时任务、PPT 助手、我的技能、客户后台、自定义作图、新对话、置顶聊天、历史聊天和账户信息自上而下排列。
- 历史聊天不再是可切换的一级功能，而是在导航展开时常驻显示；支持置顶和取消置顶。
- 定时任务、我的技能和客户后台使用右侧主界面，切换时左侧历史列表保持不变。
- 顶部右侧仅保留用量提示和深浅色切换；账户与套餐、绑定手机端、更新提醒和退出收纳在左侧底部账户菜单。
- “PPT 助手”与任务、技能、客户后台一样使用右侧主界面；新建 PPT、导入 PPT、模板管理、账户与套餐、绑定手机端和自定义作图使用弹窗。
- PPT 助手支持全部/最近查看/收藏夹筛选、网格/列表显示，以及卡片右下角更多操作菜单。
- 模板管理分为“官方模板库”和“我的模板”；官方模板可预览、选择和收藏，“我的模板”统一管理上传模板与官方收藏。
- PPT 编辑器使用独立路由；进入时收起左侧导航，退出时展开导航并返回 PPT 助手主界面。
- “客户后台”保留独立路由，顶部文字入口直达；其右侧第一个图标打开手机端绑定弹窗。
- “+ 新对话”只刷新右侧主区域，左侧仍保留历史记录与底部搜索。
- 自定义作图从右侧悬浮入口迁移到左侧主导航，点击后打开全局弹窗。
- 套餐弹窗将会员套餐与永久加油包放在同一列表展示，不设分类 Tab。

## 高保真接入原则

1. 保留 `src/app` 中的路由和状态模型；
2. 使用 Figma/Pencil 产出的组件替换 `src/components` 和页面展示层；
3. 将颜色、间距、圆角、字号映射到 `src/styles/tokens.css`；
4. 不在页面组件中耦合服务端实现，高保真阶段可将 `src/data/mock.ts` 替换为 API adapter。
